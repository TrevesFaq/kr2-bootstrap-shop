## Описание

Проект представляет собой учебную версию интернет-магазина ретрогейминга Retro Shelf (консоли, комплектующие и аксессуары), разработанную с использованием Bootstrap. Это отдельная реализация предметной области через CSS-фреймворк, а не адаптация проекта КР №1.

## Ссылка на опубликованную версию

GitHub Pages: https://TrevesFaq.github.io/kr2-bootstrap-shop/

## Тематика и кастомизация

- тема: ретрогейминг, три категории товаров: консоли, комплектующие, аксессуары;
- палитра в `css/custom.css` задана через переменные Bootstrap (`--bs-primary`, `--bs-dark`) и переопределённые `.btn-primary`, `.btn-outline-primary`;
- пиксельный шрифт Press Start 2P (Google Fonts) используется только для логотипа и заголовков (`.font-pixel`);
- вместо фото стоят заглушки `.product-photo`, в комментариях рядом указан путь `images/<id-товара>.jpg`.

## Страница товара без JavaScript

Все все товары лежат в одном файле `product.html` в блоках `section.product-view` с уникальными `id`. Ссылки из каталога и с главной ведут на `product.html#id-товара`. CSS показывает только блок, на который указывает якорь (`:target`); без якоря показывается первый товар (`:has()`).

## Используемый фреймворк

Bootstrap 5.3.8.

## Способ подключения

Bootstrap подключён через CDN (jsDelivr): CSS в `<head>`, JS Bundle перед `</body>`. Файл `css/custom.css` подключён после Bootstrap.

## Реализованные компоненты и сетка

- сетка: `container`, `row`, `col-12 col-md-6 col-lg-4`, `g-*`;
- `navbar` с выпадающим меню (единая на всех страницах);
- `card`, разные варианты карточек товаров;
- `btn` (варианты `primary`, `outline-primary`, `outline-secondary`);
- `badge`;
- `alert`;
- `modal` (быстрая заявка в каталоге);
- формы: `form-control`, `form-select`, `input-group`, `form-check`;
- `accordion` (частые вопросы на странице товара);
- `tabs` (доставка и гарантия на странице товара);
- `list-group` (контакты);
- `breadcrumb`, `table-responsive`.

## Самостоятельные доработки

- добавлена страница `contacts.html` и пункт «Контакты» в меню и подвале;
- каталог расширен до одиннадцати товаров, у карточек разные варианты: обычная, с рамкой `border-primary`, со старой и новой ценой;

- в `custom.css` добавлен плавный подъём карточки при наведении, с учётом `prefers-reduced-motion`;

## Как проверить

1. Открыть `index.html` и пройти по меню на все страницы.
2. В каталоге нажать «Заказать», окно должно открыться и закрыться.
3. В каталоге нажать «Подробнее» у разных товаров, каждый должен открыть свою карточку.
4. На странице товара раскрыть пункты accordion и переключить вкладки.
5. Проверить адаптивность в DevTools на ширинах 375, 768, 1024 и 1440 px.
